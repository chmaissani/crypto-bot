# رادار العملات الرقمية — بوت توصيات تيليغرام

بوت يشتغل على GitHub مجاناً كل 15 دقيقة، حتى لو جهازك مطفي. يفحص 16 عملة رقمية على إطار الساعة ويرسل لك على تيليغرام:

- 🔥 كل توصية جديدة مع صورة الشارت، ونقطة الدخول، وثلاثة أهداف، ووقف الخسارة
- 🎯 تنبيه عند تحقق كل هدف، كرد على رسالة التوصية نفسها
- ⛔ تنبيه عند ضرب وقف الخسارة أو انتهاء التوصية
- 📋 ملخص يومي الساعة 9 مساءً بتوقيت السعودية مع نسبة النجاح

## خطوات التشغيل

### 1) أنشئ بوت تيليغرام
1. افتح تيليغرام وابحث عن **@BotFather**
2. أرسل `/newbot` واختر اسماً ثم اسم مستخدم ينتهي بـ `bot`
3. سيعطيك **Token** يشبه `7234567890:AAH...`، احتفظ به ولا تشاركه مع أحد
4. افتح بوتك الجديد واضغط **Start**، وهذه الخطوة ضرورية

### 2) ارفع الملفات على GitHub
1. سجّل دخولك على github.com، أو أنشئ حساباً مجانياً
2. اضغط **+** أعلى الصفحة ثم **New repository**
3. سمّه مثلاً `crypto-signals-bot`، واختر **Public**، ثم **Create repository**
4. اضغط **uploading an existing file** واسحب **محتويات** المجلد كاملة، بما فيها مجلد `.github`، ثم **Commit changes**

> إذا ما ظهر مجلد `.github` بعد الرفع: اضغط **Add file → Create new file**، واكتب في الاسم `.github/workflows/signals.yml`، والصق محتوى الملف من المجلد، ثم احفظ.

### 3) أضف الـ Token كسرّ مخفي
1. داخل المستودع: **Settings → Secrets and variables → Actions**
2. **New repository secret**
3. الاسم: `TELEGRAM_BOT_TOKEN`، والقيمة: الـ Token من BotFather
4. **Add secret**

### 4) شغّل التجربة الأولى
1. افتح تبويب **Actions**، وإذا طلب منك تفعيل الـ workflows اضغط الزر الأخضر
2. اختر **رادار العملات الرقمية** من اليسار، ثم **Run workflow**، ثم **Run workflow**
3. خلال دقيقة تقريباً تصلك رسالة "✅ رادار العملات الرقمية متصل!"

بعدها البوت يشتغل لوحده كل 15 دقيقة.

## تعديل الإعدادات
كل الإعدادات في أول ملف `bot.py`:

| الإعداد | المعنى | الافتراضي |
|---|---|---|
| `COINS` | العملات المراقبة | 16 عملة |
| `MIN_SCORE` | أقل قوة إشارة للنشر، كلما ارتفع قلّت التوصيات وزادت قوتها | 2.5 |
| `REC_TTL_H` | مدة صلاحية التوصية بالساعات | 24 |
| `MAX_LEV` | سقف الرافعة المقترحة | 20 |
| `DAILY_SUMMARY_UTC_HOUR` | ساعة الملخص اليومي بتوقيت UTC | 18، أي 9 مساءً بتوقيت السعودية |

## ملاحظات
- **المستودع العام (Public)** دقائق تشغيله مجانية بلا حد. أما **الخاص (Private)** فله 2000 دقيقة شهرياً فقط، فإذا جعلته خاصاً غيّر `*/15` إلى `*/30` في ملف `signals.yml`.
- GitHub قد يؤخر التشغيل المجدول بضع دقائق في أوقات الضغط، وهذا طبيعي.
- البوت يحفظ حالة التوصيات في `state.json` تلقائياً، فلا تعدّل هذا الملف يدوياً.
- الإرسال لقناة أو مجموعة: أضف البوت مشرفاً فيها، وأضف سراً ثانياً باسم `TELEGRAM_CHAT_ID` وقيمته معرّف القناة، مثل `@my_channel`.
- التوصيات ناتجة عن تحليل فني آلي وليست نصيحة مالية. البوت لا يملك أي وصول لحساباتك ولا ينفّذ صفقات.
